2. О проекте

InnovaAuto — автомобильный маркетплейс Таджикистана: покупка, продажа и поиск авто с фильтрами по марке, модели, цене, году, городу и типу кузова. Сейчас сервис работает как веб-платформа (inovaauto.com).

Мобильное приложение даст пользователям быстрый доступ к каталогу, избранному, уведомлениям и размещению объявлений без браузера — в формате App Store и Google Play. Разработку ведёт IT-компания WebDushanbe.

3. Цель

  • Выпустить рабочее приложение для iOS и Android за 1,5 месяца.
  • Покрыть ключевые сценарии сайта: поиск, просмотр, избранное, кабинет, размещение объявления.
  • Подключить существующий backend сайта (API), без полной перестройки сервера.
  • Подготовить сборки к публикации в App Store и Google Play.

4. Технологический стек

Клиент

  • Flutter — один код для iOS и Android
  • Адаптивный UI под телефоны
  • Локальное кэширование каталога и избранного

Сервер и публикации

  • REST API на базе текущего backend сайта
  • Авторизация (email / телефон)
  • Push-уведомления (Firebase)
  • Сборки: TestFlight + Google Play Internal

Flutter выбран намеренно: при бюджете 90 000 с. и сроке 1,5 месяца это единственный реалистичный путь выпустить обе платформы без урезания ядра продукта.

5. Функционал MVP (входит в бюджет)

Каталог и поиск

  • Лента объявлений
  • Поиск по бренду / модели / городу
  • Фильтры: цена, год, пробег, КПП, топливо, город, тип кузова
  • Сортировка и пагинация

Карточка авто

  • Галерея фото
  • Характеристики и описание
  • Контакты продавца (звонок / мессенджер)
  • Поделиться объявлением

Аккаунт

  • Регистрация и вход
  • Профиль / личный кабинет
  • Избранное
  • Мои объявления (список, статус)

Продажа

  • Форма размещения объявления
  • Загрузка фото с камеры / галереи
  • Редактирование и снятие с публикации

Уведомления

  • Push о статусе объявления
  • Базовые системные уведомления

Сервисные экраны

  • Онбординг / пустые состояния
  • Офлайн-заглушка
  • Политика конфиденциальности
  • Светлая / тёмная тема

6. Вне MVP (отдельный этап)

  • Чат между покупателем и продавцом внутри приложения
  • Полноценная карта объявлений
  • Сравнение авто (таблица)
  • VIP-оплата и тарифы внутри приложения (IAP)
  • Блог / контент-раздел
  • Админ-панель в мобильном виде
  • Отдельные нативные приложения на Swift + Kotlin

Эти пункты можно оценить и запустить после релиза MVP, не блокируя выход в сторы.

10. Условия и риски

  • Срок 1,5 месяца реалистичен при готовом (или быстро адаптируемом) API сайта и оперативной обратной связи по макетам.
  • Задержки на стороне доступов, модерации сторов или контента не входят в календарь разработки.
  • Изменение scope после утверждения ТЗ пересчитывается отдельно.
  • Публикация в App Store / Google Play зависит от прохождения модерации платформ; мы готовим материалы и сопровождаем первую подачу.
