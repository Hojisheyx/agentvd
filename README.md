# Лазерная клиника

Одностраничный сайт для клиники лазерной эпиляции и косметологии в Душанбе
([@lasernaya_clinica](https://www.instagram.com/lasernaya_clinica/)).

## Запуск

```bash
python3 -m http.server 4173
```

Откройте http://localhost:4173
